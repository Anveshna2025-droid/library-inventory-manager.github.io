# Library Inventory Manager

This is a simple command-line library management system built in Python for Lab 3. It allows a user to add books, issue and return books, search by title, and view the current inventory. The data is stored in a JSON file so that the library state is preserved between runs.

## Features

- Add a new book with title, author, and ISBN  
- Issue a book using its ISBN  
- Return a previously issued book  
- View all books with their current status (available / issued)  
- Search for books by a part of the title  
- Store and load book records from a JSON file (`library_data.json`)

## Technologies Used

- Python 3  
- Object-Oriented Programming (Book and LibrarySystem classes)  
- JSON file handling (`json` module)
